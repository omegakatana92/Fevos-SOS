# Fevos-SOS — Native Game Recompilation

Fevos-SOS is a native game recompilation project designed to bring the original gaming experience to modern PC platforms, including Windows, Linux, and Steam Deck.

The project focuses on native execution, platform compatibility, and preserving the original gameplay experience without relying on traditional console emulation.

## Project Features

- Native recompilation of the original game.
- Completed Windows executable (`.exe`).
- Completed Linux and Steam Deck AppImage (`.AppImage`).
- Cross-platform support for modern systems.
- Dedicated native builds for easier installation and launching.
- Continued development focused on compatibility, stability, and performance improvements.

## Supported Platforms

- **Windows:** Native executable.
- **Linux:** Native x86-64 AppImage.
- **Steam Deck:** Linux AppImage compatible with SteamOS.
